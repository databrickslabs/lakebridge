BladeBridge supports conversion from various ETL and data integration platforms to Databricks. Select your source system below to see detailed conversion guides, supported components, and migration strategies.

## Getting Started

To convert your ETL sources to Databricks:

1. **Export your sources** in the appropriate format (e.g., DTSX files for SSIS)
2. **Review the conversion guide** for your source system
3. **Run the Lakebridge transpiler:**
   ```bash
   databricks labs lakebridge transpile \
     --source-dialect <your-source> \
     --input-source /path/to/sources \
     --output-folder /path/to/output
   ```
4. **Review generated code** and conversion notes
5. **Test and deploy** to Databricks

For detailed CLI instructions, see the [Transpile Guide](../index.mdx).
